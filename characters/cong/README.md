# Cong 娘参考设定 v0.1

## 视觉锚点

彩羽小鸟拟人，不是鲸鱼。深钴蓝至天蓝长发、弯曲呆毛、不对称彩虹冠羽、玫红瞳色、金色交叉发夹、耳侧短羽、橙红色领巾、蓝白黄羽翼披肩、圆蓝鸟鞋舌装饰。默认白底，日系动画线稿与赛璐璐上色。黄色蝴蝶是可选伴生意象。

建议色板（近似参考）：深蓝 `#163D88`、钴蓝 `#487DD5`、天蓝 `#9BD3F5`、浅白 `#F7F5F6`、橙红 `#FF713C`、金黄 `#FFD65C`、玫粉 `#F58BB5`。

Q 版约三头身；常规比例保留同款服装及生物特征。三视图尽量采用相同站姿、等高、白底、统一色彩，避免透视失真。局部参考包含眼睛、彩冠、领巾、披肩、鞋、尾羽。设定图所示身高、性格及身份均为虚构创作提案，并非真实人物资料。角色参考不是唯一合法画法。

## 资产制作规范

- PNG：优先保留原始分辨率，白底参考图；透明底需要另行制作并标明。
- GIF：方形或近方形，循环播放，记录帧数和实际帧率；不把静态九宫格标为动画。
- Prompt：单独 UTF-8 文本，说明比例、衣装、颜色、构图与约束。
- 每个新增文件记录作者、出处、AI/人工创作方式、许可、尺寸和版本。
- 禁止把鲸尾、鲸鳍耳或鲸鱼娘原装束作为 Cong 娘的默认生物特征。
